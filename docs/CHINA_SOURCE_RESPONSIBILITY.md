# 中国岗位来源：自动搜集与人工检查责任清单

最后更新：2026-08-01

## 使用原则

这份清单用于区分 Ivy Job Radar 当前能够自动处理的来源，以及仍需要人工检查的来源。

- “进入公司池”不等于“已经稳定采集”。
- “已尝试扫描”不等于“成功读取岗位”。
- 系统显示 0 个岗位，不等于该公司当前没有招聘。
- 历史 JD Excel 只用于公司发现、岗位别名、技能词和 CV 关键词分析，不用于判断当前是否在招。
- 历史 JD、旧岗位链接、旧开放状态和历史证据数量不得写入公司池或显示为当前岗位。
- 只有重新访问当前官方招聘入口并核验仍开放的岗位，才可进入“今日岗位 / 可申请岗位”。

## 1. Ivy Job Radar 能自动搜集的来源

| 来源 | 当前能力 | 当前边界 |
|---|---|---|
| 公开结构化 ATS | 读取职位列表、JD、地点和申请链接，标准化并去重 | 中国入口尚需连续运行验证；租户 WAF、地区选择或特殊配置仍可能导致失败 |
| 普通公司招聘官网 | 每日访问并尝试识别公开职位页、JSON-LD 和岗位链接 | 动态页面、地区筛选、微信公众号入口和登录墙可能无法稳定读取 |
| 公开网页搜索 | 发现公司官网、公开职位页和可访问的招聘信息 | 只能补漏，不能保证覆盖平台登录后的全部岗位 |
| 历史 JD Excel | 提取岗位别名、技能词和 CV 用词 | 只作独立历史语料库，不生成当前岗位 |
| 招聘提醒邮件 | 计划解析提醒邮件中的岗位并去重 | 尚未完成邮箱授权，当前没有运行 |

## 3. 中国招聘平台分工

| 平台 | 当前能否自动完整收集 | 人工检查建议 |
|---|---:|---|
| BOSS直聘 | 不能 | 每天或隔天 |
| 猎聘 | 不能 | 每天或隔天 |
| 智联招聘 | 不能 | 每周两次 |
| 前程无忧 | 不能 | 每周两次 |
| 脉脉 | 不能 | 每周一次，重点检查内推和招聘动态 |
| 牛客 | 不能 | 每周一次，重点检查校招、提前批 |
| 拉勾 | 不能 | 每周一次，补充 Tech 和医疗科技 |
| 国聘、应届生 | 只能发现部分公开页面 | 校招季每周一次 |
| 微信公众号 | 基本不能稳定自动采集 | 每周检查重点公司公众号 |
| 学校就业网 | 可发现部分公开页面，无法保证及时 | 校招季每周一次 |

## 4. 当前人工检查安排

- 每天或隔天：BOSS直聘、猎聘。
- 每周两次：智联招聘、前程无忧。
- 每周一次：脉脉、牛客、拉勾、国聘、应届生和重点公司公众号。
- 每周一次：抽查 Tech、Quant、Consulting 的官方招聘页。
- 优先人工检查自动扫描失败、无法识别岗位结构或尚未核实可靠招聘入口的公司。
- Ivy Job Radar 继续负责公开官网、标准 ATS、公开网页搜索、去重和当前开放状态核验。

## 5. 当前生产证据

2026-07-31 的生产运行尝试扫描全部 176 家公司：

- 66 家成功；
- 102 家无法识别；
- 8 家失败；
- 合计 110 家仍为失败或无法识别；
- 公司门户得到 11 个匹配岗位。

这些数字是全公司池结果，并非仅中国公司结果。后续只有按中国公司单独生成连续运行记录，才能判断中国侧的真实稳定覆盖率。

## 6. 何时可以从人工清单移除

只有同时满足以下条件，某家公司或来源才可从高频人工检查清单中移除：

1. 能连续读取真实职位列表，而不是只打开招聘首页；
2. 能保存岗位名称、完整 JD、地点、发布时间或可核验状态、申请链接；
3. 连续运行期间没有异常归零；
4. 失败会被记录并告警，而不是被误报为“0 个岗位”；
5. 至少完成 7 天连续稳定验证。

即使达到上述标准，平台独占岗位、App 内推荐流、微信公众号岗位和未同步官网的第三方岗位仍可能需要低频人工抽查。
