# 公司关注池

入口：工具 → 公司关注池，路径 `/company-watchlist`。

管理公司名称、官网/招聘链接、2027 届岗位线索和系统最近检查时间；没有申请状态、匹配分数或自动投递行为。申请记录和现有岗位池不受影响。

## 首批名单

来源：用户提供的《中国医药及相关公司名单 (2).xlsx》，“公司名单”工作表 A6:M317。
只提取 B 列公司名称、F 列校园招聘、G 列总招聘；没有招聘链接时保留 K 列公司首页并标注待补充。
共 312 家：190 家有表中招聘链接，25 家只有首页，97 家缺少链接。保留同一公司的不同入口和 ATS URL 的查询参数、hash，不把“未定位”等文字变成链接。未导入核验结论或申请明细，也未重新核验链接有效性。

首次进入页面通过带登录身份的 POST 初始化到独立 D1 表 `company_watchlist`。`company_watchlist_imports` 记录每个用户的导入标记。导入与标记在同一原子批次内完成；重试不会覆盖修改或恢复已移除公司。GET 不导入数据。数据查询和写入始终限定登录用户，表结构按需初始化。

## 2027 届岗位线索合并（2026-09-23）

从《中国2027届统计AI研究校招岗位_2026-09-23.xlsx》导入 46 个公司分组、65 条岗位线索，其中 6 家与原有 312 家名单重合，合并后预计为 352 家。养生堂/万泰生物的两条线索归在原有“养生堂”记录下，保留原始公司名称。岗位单独保存于 `company_watchlist_positions`，按用户、公司、标准化岗位标题去重；不写入现有 `jobs` 或申请表。每条保留地点、优先级、证据等级、官网入口、证据链接、备注及原表核查日期。公司原有招聘链接保留，新增官网入口按 URL 去重；导入标记保证再次打开页面不重复。

这个页面展示研究线索，证据等级不等于实时开放状态；站点“最近检查”仍须真实监控后更新。

## 监控边界

此版本只完成持久化名单管理，尚未连接定时扫描器。API 明确返回 `monitoringEnabled: false`，页面也提示未接入。`last_checked_at` 为空，不使用导入日期或原 Excel 核验日期冒充新检查；修改链接后清空旧检查时间。
现有 Python 公司扫描读取静态 `app/company-pool.json` 等文件，不会自动读取此 D1 表。后续需要独立接入名单读取、分站解析、真实检查回写及岗位去重入库，不能仅检查页面 HTTP 200 就声明岗位监控成功。
