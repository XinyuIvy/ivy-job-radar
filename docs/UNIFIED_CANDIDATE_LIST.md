# Unified Candidate List

The Saved area is one candidate pool, not two workflow statuses.

- Saved/bookmarked jobs and applications still in `准备材料` appear in the same list.
- The UI does not expose separate “收藏” and “待提交申请” buckets or status toggles.
- If the same logical job exists in both sources, it appears once, using the application record as the richer representation.
- Creating an application record from a saved job keeps the item in the same candidate list instead of moving it between tabs.
- Submitted/interview/offer/rejected applications remain in the separate Applications view.
